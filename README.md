🚖 City Ride – Taxi Fare Analysis Dashboard

1. 📌 Project Overview
City Ride – Taxi Fare Analysis Dashboard is an end-to-end Business Intelligence project developed in Power BI to analyze taxi booking and fare data. The dashboard provides valuable insights into booking trends, revenue generation, trip performance, customer ratings, cancellations, and vehicle-wise performance.

The project helps taxi companies and business stakeholders understand operational efficiency, identify revenue opportunities, monitor customer satisfaction, and make data-driven decisions.

2. 📖 Short Description
An interactive Power BI dashboard built to analyze taxi booking data by tracking rides, revenue, cancellations, customer ratings, vehicle performance, and operational KPIs. The dashboard enables users to explore business performance through dynamic filters, charts, and drill-down reports.

3. 🛠 Tech Stack
Power BI – Designed and developed interactive dashboards for data visualization and business reporting.
Power Query – Cleaned, transformed, and prepared raw data for analysis using ETL operations.
DAX (Data Analysis Expressions) – Created calculated columns, measures, and KPIs for advanced analytics.
Data Modeling – Established relationships between tables to enable accurate and efficient reporting.
Microsoft Excel – Used as the data source for importing and managing taxi booking data.
Data Visualization – Built interactive charts, slicers, cards, maps, and graphs to present business insights effectively.
